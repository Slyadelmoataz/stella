# My Next PWA

Next.js App Router starter with TypeScript, Tailwind CSS, and `next-pwa`.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000. The service worker is disabled in development and generated for production builds.

## Production build

```bash
npm run build
npm start
```

Serve production over HTTPS to enable service workers and mobile installation. PWA manifest: `public/manifest.json`; icons: `public/icons/`.
